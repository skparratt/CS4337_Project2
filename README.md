# CS4337 Project 2 - Sarah Parratt

## Description

This project implements the Prolog backend for a work schedule planner. The main predicate is plan/1, which creates a schedule for morning, evening, and night shifts.

## Files

- project2.pl: Main Prolog source file.
- devlog.md: Development log for the project.
- README.md: Project description and run instructions.
- example-input-1.pl: Simple test input file used to test plan/1.

Open SWI-Prolog in the project folder.
